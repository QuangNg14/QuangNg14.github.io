My work at Microsoft

The engineering problems I work on and the decisions I make when software, data, and AI meet.

Connecting agents to useful tools

I configure and troubleshoot Model Context Protocol (MCP) integrations. I use GitHub Copilot and its CLI to turn repeatable coding and pull-request tasks into reusable workflows, leaving the change small enough for a person to review.

Evaluating an agent before release

I ground agent responses in authoritative sources, pair model output with deterministic checks, and rerun evaluations against a versioned build. That makes it possible to distinguish a change in agent behavior from a change in what was tested.

Promoting the build that passed

I automate staged CI/CD releases: build once, validate in staging, then promote the same artifact. Test gates, a record of what shipped, and a rollback path are part of the release, not cleanup afterward.

Keeping data pipelines trustworthy

I trace incorrect results back through ingestion, transformation, and reporting. I build repeatable processing steps and add checks for data meaning and consistency, not just whether a job finished.

Running services on Azure

I scope workload identities to the access they need, improve access controls, and use logs and telemetry to diagnose failures. I make infrastructure changes reviewable and validate them before rollout.

Turning requirements into validation

I translate requirements into explicit acceptance checks and build reusable validators. When a rule changes, I test existing consumers as well as the new case so data that used to pass doesn't silently start failing.
